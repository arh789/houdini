# Houdini Basics - Concise Learning Path

This core track condenses the full 23h 33m Basics syllabus into a practical route for reaching the POPs, Vellum, RBDs, FLIP, and Pyro sections.

- **Simulation-ready path:** approximately 12-13 hours, excluding Copernicus
- **Complete modern foundation:** approximately 14-15 hours, including Copernicus
- **Approach:** retain prerequisites and selected exercises; move contextual, specialised, and duplicate material to optional study

## 1. Setup and Orientation - approximately 20 minutes

1. Using the Website
2. Installation and Licensing
3. Houdini 22

## 2. Interface and Node Workflow - approximately 1 hour

1. Interface I - Basics / Crash Course
2. Tree View vs. Networks
3. The Geometry Spreadsheet
4. Flags / Ghosting
5. Interface II: Working with the Node Network
6. Contexts
7. Common Bugs

## 3. Geometry and Data Fundamentals - approximately 2 hours

1. Transform Objects / Pivots
2. Basic Shapes and Test Geometries
3. Groups
4. Basic Curves
5. Attributes and Attribute Classes
6. Vertices vs. Points
7. Data Types
8. Attribute Promote
9. Paint Attributes
10. Parameter Expressions

## 4. Procedural Modelling - approximately 2-2.5 hours

1. Boolean Node
2. Match Size
3. Scatter I - Basics
4. Scatter and Align
5. The Ray Node
6. Deformers
7. Reducing / Remeshing Geometry
8. Groups II
9. Measure
10. The Magic Node: Point Deform

## 5. VEX and Procedural Logic - approximately 2 hours

1. VEX and VOPs
2. VEX II - Parameters and Variables
3. VOPs II
4. Comparisons
5. For Loops
6. Masking
7. Attribute from Textures
8. Trace

## 6. Production Geometry Workflows - approximately 2 hours

1. File Access I - Reading / Importing
2. Packed Geometry
3. Pack / Unpack / Convert
4. Multi Copy
5. The Add Node
6. Assets
7. File Access II - Exporting
8. File Access III - Caching
9. Performance Monitor

## 7. Volumes, SDFs, and Noise - approximately 2.5-3 hours

1. Volumes
2. VDBs - Volumes 2.0
3. SDFs - Signed Distance Fields
4. Randomness
5. Noise
6. `fitRange()` / Remap
7. `curlnoise`
8. `@rest` Position
9. Complete either [Example] Grass Field or [Homework] Snow Generator

## 8. Required Practice and Checkpoints

1. [Example] Donut I - Scale
2. [Example] Donut II - Rotation

4. Complete one substantial homework project:
   - [Homework] Palisade Tool

5. Quiz - Fundamentals I
6. Quiz - Fundamentals II

## 9. Optional Copernicus Branch - approximately 2 hours

Complete this branch for a broader modern Houdini foundation. It is not required before beginning the simulation sections.

1. COPs Basics I
2. COPs Basics II - Texture Workflow
3. Texture Generation (Noise / UVs)
4. Tile Pattern Node
5. COPs - SDF
6. COPs - Working with Geometry

## Recommended Use

Follow the numbered stages in order. Do not omit the selected examples, homework project, or quizzes: they test whether the concepts can be applied independently rather than merely recognised while watching a lesson.
